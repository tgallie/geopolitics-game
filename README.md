# World Conquerer

A turn-based, single-player strategy web application inspired by the classic game Risk. The player selects a starting country and must conquer 9 other randomly selected nations while competing against AI-driven Non-Player Characters (NPCs).

## 🌍 Live Deployment
**https://geopolitics-game-pi.vercel.app/**

## 🚀 Tech Stack
* **Framework:** Next.js 16 (App Router, React 19, TypeScript)
* **Styling:** Tailwind CSS v4
* **Database:** MongoDB Atlas (NoSQL)
* **Authentication:** Better Auth (Email/Password)
* **AI Integration:** Google AI Studio (Gemini 3.1 Flash-Lite via OpenAI-compatible API)
* **Testing:** Node.js Native Test Runner (31 automated tests)

## ✨ Core Features
* **Custom Battle Engine:** Implements exact game rules including paired dice mechanics, tie logic (no losses), troop reinforcements, transfers, and conquest bonuses.
* **AI NPC Strategy:** NPCs make strategic decisions to attack, reinforce, and transfer troops.
* **Dynamic AI Commentary:** Battle events are narrated in real-time by an LLM, providing lively, accurate, and context-aware commentary on casualties and outcomes.
* **Robust Fallback System:** If the AI API times out or fails, the app gracefully falls back to a deterministic summary generated by the game engine, ensuring the game never crashes.
* **Spectator Mode:** Players can generate read-only links to allow others to watch their game in real-time.
* **Security:** Secure authentication, server-side validation, origin request verification, and atomic database revisions to prevent cheating (e.g., moving twice or closing the browser mid-attack).

## 🗄️ Database & Architecture
The application uses MongoDB for data persistence, with a clear separation of concerns:
* **Repositories:** Database queries are isolated in `src/lib/db/` for security and maintainability.
* **Game Engine:** Pure TypeScript logic (`src/lib/game/`) handles all state changes and rule validation.
* **Auth Store:** Better Auth manages users and sessions securely.
